# Codex Context Bar v1.0.0

首个打包发行版本：专为 Codex 打造的原生 macOS 菜单栏工具。

## 下载与安装

需要 **macOS 14 或更新版本**。Apple Silicon（M 系列）选择 `arm64`；Intel Mac 选择 `x86_64`。

- **DMG**：打开磁盘映像，将 Codex Context Bar 拖入 Applications，然后从应用程序启动。
- **ZIP**：解压后将应用移入 Applications。
- **SHA-256**：下载对应 `.sha256` 和两个安装包后，可运行 `shasum -a 256 -c Codex-Context-Bar-1.0.0-macos-<架构>.sha256` 校验。

这是菜单栏应用，启动后点击屏幕顶部的图标选择 Codex 项目。

**签名状态：本地 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。** macOS 可能阻止首次打开。如果确认下载来源和校验值可信，可在系统设置的“隐私与安全性”中使用系统提供的“仍要打开”入口。不要关闭系统安全保护。尚无自动更新功能。

## 本次功能

- 本地查看 Codex 会话中的技能、记忆、插件和其他上下文说明。
- 近 7 / 30 天项目与所有项目用量统计，显示潜在节省与计价覆盖范围。
- 修改前预览作用范围和配置差异，保存后等待新任务验证，支持撤销目标键。
- 中英文界面、跟随系统 / 浅色 / 深色主题、0–100% 磨砂玻璃透明度（默认 85%）。

## English

First packaged release of Codex Context Bar, an independent native macOS menu bar app for Codex.

Requires **macOS 14+**. Choose **arm64** for Apple Silicon or **x86_64** for Intel. Open the DMG and drag the app to Applications, or extract the ZIP. Launch from the menu bar icon. SHA-256 checksum files are included.

Builds are **ad-hoc signed, not Developer ID-signed or notarized**. macOS may block the first launch. After verifying the download source and checksum, use the system-provided Open Anyway option in Privacy & Security if needed; do not disable system security protections. There is no automatic updater.

Includes local context inspection, recent usage estimates, configuration previews and undo, fresh-task verification, bilingual UI, theme selection and adjustable frosted glass. Costs are estimates from static reference rates, not billing data or guaranteed savings. Both architectures are tested and packaged in GitHub Actions; live desktop behavior and every supported OS version are not comprehensively verified.
